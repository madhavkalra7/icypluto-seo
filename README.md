# Icypluto SEO Agent Skills

This repository contains custom Agentic Coding Skills for Antigravity (and compatible AI agents) to perform automated, self-healing SEO, Performance, Accessibility, and Generative Engine Optimization (GEO) audits on web codebases.

## 📁 Repository Structure

*   **[skills/icypluto-seo/](file:///e:/icypluto%20seo%20skills/skills/icypluto-seo)**: The core skill bundle containing the executable workflows and thematic guidelines.
    *   [SKILL.md](file:///e:/icypluto%20seo%20skills/skills/icypluto-seo/SKILL.md) — The central **Lighthouse Self-Healing Loop** workflow.
    *   [site_structure.md](file:///e:/icypluto%20seo%20skills/skills/icypluto-seo/site_structure.md) — Guides for headings, semantic layout, and structural SEO.
    *   [performance_accessibility.md](file:///e:/icypluto%20seo%20skills/skills/icypluto-seo/performance_accessibility.md) — Techniques for layout shifts (CLS), script loading, and accessibility attributes.
    *   [structured_data.md](file:///e:/icypluto%20seo%20skills/skills/icypluto-seo/structured_data.md) — Dynamic schema injection and markup guidelines.
    *   [geo_optimization.md](file:///e:/icypluto%20seo%20skills/skills/icypluto-seo/geo_optimization.md) — Generative Engine Optimization patterns for visibility and citations.
    *   [brand_authority.md](file:///e:/icypluto%20seo%20skills/skills/icypluto-seo/brand_authority.md) — Establishing trust, sentiment signals, and testimonial layouts.

## 🚀 How to Use

AI Agents automatically discover and load the skills in this repository:
1. When asked to audit or optimize a web codebase for SEO/Lighthouse, the agent triggers the `icypluto-seo` skill defined in [skills/icypluto-seo/SKILL.md](file:///e:/icypluto%20seo%20skills/skills/icypluto-seo/SKILL.md).
2. The agent compiles the application, spins up a local server, runs a headless Lighthouse audit, and iterates until the target thresholds are met.
